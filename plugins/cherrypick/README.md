# Cherry Pick

A [Stash](https://github.com/stashapp/stash) plugin that learns what you like from your own ratings and plays and shows it inside Stash's pages: a For you row on the front page, Your score on scenes you haven't rated, More like this on scene pages, and performer and scene brackets that sharpen what it learns.

Cherry Pick is in development and has no release yet. The plan is tracked in [Cherry Pick 0.1.0](https://github.com/CandyBoudoir/candyboudoir.github.io/issues/45).
